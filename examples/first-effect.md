# 第一练习：蓝色命中闪光

这是开始使用 skill 的练习说明，没有预先生成贴图或 UE 资产。

复制给 AI：

> 使用 $ue5-vfx-step-by-step。我要做一个蓝色命中闪光，大约半秒内出现并消失。先只做一个柔光主形状，不加碎片、烟雾和拖尾。请先确认我的 UE 版本和现有进度，每次只带我完成当前阶段的少量操作。

## 分轮目标

1. **确定形状**：一个柔光圆点，背景可透，主要靠蓝色和快速消失表达命中。已有合适遮罩就复用；没有则选当前版本可用的径向渐变或一张灰度遮罩。
2. **做好材质**：使用材质参考里的最小结构，Tint 先白色、Intensity 先 1，先看形状和透明度。材质在测试粒子上通过后再调蓝色。
3. **让一个粒子播放一次**：Burst Count=1，Lifetime=0.5 秒，Sprite Size=50×50 cm 是可调整的试做起点。相机距离不同需要改尺寸。核对非循环与生命周期，不提前发射几百个粒子。
4. **让它消失**：在当前版本对应的颜色缩放模块中，RGB 保持白色，Alpha 按 Normalized Age（0–1）从 1 降到 0。核对材质实际使用了 Particle Color 的 Alpha。
5. **对照画面只改一项**：太暗先查曝光/材质；太小改尺寸；消失太快改寿命或曲线；还不像命中时再考虑尺寸扩张曲线。

每轮只有画面或工具读回支持后才记录为完成。完成主效果后再决定是否加第二层；上述尺寸、时长和曲线均为练习起点。
