# 彩色、去色和遮罩图卡

图卡的目的：把颜色暂时放到一边，让用户看清形状、明暗与时间变化。

## 三种图不能混为一谈

| 图 | 看什么 | 不能据此确认什么 |
| --- | --- | --- |
| 彩色参考 | 色相、颜色搭配和可见形状 | 隐藏的原始贴图/节点 |
| 同图去色 | 明暗、边缘和轮廓；保留同一时间和裁切 | 原始遮罩或真实发光强度 |
| 遮罩贴图 | 真实资产使用的形状通道 | 单靠 RGB 预览无法保证 Alpha/R 正确 |

默认模板的白色圆环是原创“遮罩示意”。它不来自游戏素材，不能冒充原始遮罩。用户提供实际贴图时显示“贴图预览”，先确认采样通道再决定是否称为遮罩。

实际去色使用 HTML 的 CSS 滤镜，只改变显示；Python 工具只包装已有文件，不改变图片像素。CSS 去色不是曝光测量、线性亮度分析或原始通道提取。需要栅格图片生成或编辑时使用当前可用图像工具；保留原图，不把 AI 重画当精确像素证据。

## 使用现成图卡

[assets/layer-card.html](../assets/layer-card.html) 可离线打开。默认示意为一层扩散圆环：
- 彩色、同图去色、白环遮罩示意。
- 出现、扩大、消失的时间示意。
- “环宽”控件只改变厚薄，供用户比较。
- 本地文件选择可放入整体参考、真实单层截图或真实贴图；不上传、不自动拆层。

只有整体截图时，让整体图单独显示；单层仍标“结构示意”。禁止把整体截图塞进“真实单层”格冒充隔离结果。用户选择单层文件也只证明提供了文件，仍应核对它是否有其他层。

## 用脚本保存带图的单文件卡

脚本使用 Python 标准库，路径按本 skill 所在位置解析：

```powershell
python "<skill目录>/scripts/build_layer_card.py" --title "冲击波：圆环层" --reference "参考.png" --layer "独立圆环截图.png" --texture "圆环贴图.png" --out "圆环分析.html"
```

三个图片参数都可省略，只支持 PNG/JPG/WebP。省略的格子保持明确的结构示意。不要把示例文件名当成真实存在的资产。输出为 HTML，图片嵌入其中，离线可打开；原图不改，避免将私有课程/工程截图随图卡上传到公开仓库。

保存后打开卡片检查标题、图与状态标签；看一张去色图是否和对应彩色图裁切、大小一致。默认关掉自动补全整个特效的冲动：图卡下只写这层的修改和用途方向。

## 时间与不确定性

视频卡选同一层的出现/最明显/消失三帧，注明真实时间戳；保持比例和裁切一致。只能看到静图时不编造时间轴，用“运动推测”或“试做示例”。

从图中裁取一块区域不等于去掉了叠加层。真实资产允许时可在工程副本中单独启用目标发射器/Renderer 对照；隔离资产与截图仍需核对其内部包含几种视觉元素。没有工程时保持观察和推测的边界。

## 把当前层的表格放进卡片

脚本不会分析图片。AI 先按本 skill 完成单层表格，再把文字写入 JSON，通过 `--analysis "本层分析.json"` 一起打包。有分析文件时，卡片使用这些文字，并隐藏默认圆环的环宽和时间示意，避免套到其他效果上。

JSON 格式示例（分析者需将“推测”换为实际证据状态）：

```json
{
  "summary": "这层像慢慢散开的烟，负责保留爆炸后的余烟。",
  "rows": [
    {"item": "贴图", "method": "推测：柔边烟雾纹理", "role": "提供烟团轮廓"},
    {"item": "材质", "method": "推测：灰色、半透明", "role": "让背景透出来"},
    {"item": "粒子", "method": "静图无法确认运动", "role": "控制烟团位置与消失"},
    {"item": "作用", "method": "推测：爆炸后的余烟", "role": "延长爆炸后的视觉余韵"}
  ],
  "changes": [
    {"goal": "烟更薄", "where": "材质透明度，先核对控制来源", "result": "背景更容易透出来"}
  ],
  "uses": [
    {"direction": "爆炸", "role": "余烟", "change": "先调整出现时间"},
    {"direction": "落地重击", "role": "尘土", "change": "先调整颜色与漂移方向"}
  ]
}
```

有文字分析但没有真实单层图时，模板仍明确显示“圆环结构示意”，不把这个图标成烟雾或当前层的真实外观。更合适时可只交付表格，不使用不匹配的示意；需要新视觉时另画并标记“结构示意”。
